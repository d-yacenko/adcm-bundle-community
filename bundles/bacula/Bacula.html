📖 About Bacula

Bacula is a cross-platform enterprise‑grade backup and recovery system. It enables you to schedule backups of files, databases, system images, and more. With Bacula you can:

  • Define backup jobs with flexible schedules (daily, weekly, monthly, etc.)
  • Back up data from multiple clients to one or more storage hosts
  • Restore files to any client from any backup job
  • Monitor job status, disk usage, and backup history

Sequential installation of all components: PostgreSQL → Client → Storage → Director.
After installation, Director automatically registers existing Clients and Storage.
Backup Job Creation: During installation, a backup job is created for each Client, linking it to the selected Storage host. This ensures that every Client is immediately ready for backup operations.

🔄 Service‑level Actions
⚙️ Configuration Management: Before using the service‑level actions below, you need to define the backup paths for each client and the storage devices for each storage host. This is done via configuration groups in ADCM:
  • For each Client, specify the list of directories to back up (Fileset).
  • For each Storage, define the device name and the corresponding filesystem path for storing backup volumes.
After updating the configuration, run the Reconfig action for the respective service (Client or Storage) to apply the changes to the Director.
Storage → Reconfig
Reconfigure Storage
Synchronise storage device configurations to Director, creating or updating Storage and Device blocks for all hosts in the service.
Client → Reconfig
Reconfigure Client
Synchronise fileset configurations to Director, creating or updating FileSet blocks with backup paths for all hosts in the service.
Director → Status
Status
Display the current status of the Director daemon, including running jobs, scheduled jobs, terminated jobs, and device status.
