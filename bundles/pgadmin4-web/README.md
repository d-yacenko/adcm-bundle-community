## pgAdmin 4 Web (ADCM bundle)

### Доступ к веб‑интерфейсу

После установки и запуска сервиса **pgadmin4_web** веб‑интерфейс pgAdmin 4 по умолчанию доступен по URL:

```text
http://<IP_хоста>:28080/pgadmin4
```

- `<IP_хоста>` – адрес хоста, на котором развернут сервис (например, `10.129.0.33`).
- Порт `28080` и префикс пути `/pgadmin4` можно изменить в конфигурации сервиса:
  - параметр `http_port` – HTTP‑порт Apache VirtualHost для pgAdmin;
  - параметр `base_url` – URL‑префикс для pgAdmin (по умолчанию `/pgadmin4`).

При изменении настроек URL будет иметь вид:

```text
http://<IP_хоста>:<http_port><base_url>
```
